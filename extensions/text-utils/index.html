text-utils

统一换行符、清理首尾空白。一个无需原生依赖的纯 JavaScript 扩展。

v0.1.0 · 已签名发布
ON THIS PAGE安装与调用扩展信息版本记录能力接口

安装与调用

先配置可信索引与公钥根，再使用以下命令。首次发布前可参考开发文档在本地构建体验。

foundry install text-utils
foundry run text-utils normalize --input '{"text":"  hello  "}'
