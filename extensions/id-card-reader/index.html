OFFICIAL EXTENSION / JavaScript

id-card-reader

固定结构的模拟身份证信息：姓名、证件号、签发机关、有效期与照片字段。

v0.1.0 · 首次签名发布准备中
ON THIS PAGE安装与调用扩展信息版本记录能力接口

身份证读卡器 · 模拟插件
此版本使用模拟设备和固定数据，不会读取真实身份证、打开摄像头或执行真实 OCR。

安装与调用

先配置可信索引与公钥根，再使用以下命令。首次发布前可参考开发文档在本地构建体验。

foundry install id-card-reader
foundry run id-card-reader read-card --input '{}'

扩展信息

实现类型JavaScript (javascript)
