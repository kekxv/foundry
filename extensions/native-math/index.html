OFFICIAL EXTENSION / 动态库

native-math

通过 libffi 调用动态库。用显式 C ABI 声明连接 JavaScript 与原生代码。

v0.1.0 · 已签名发布
ON THIS PAGE安装与调用扩展信息版本记录能力接口

安装与调用

先配置可信索引与公钥根，再使用以下命令。首次发布前可参考开发文档在本地构建体验。

foundry install native-math --grant native.call
foundry run native-math add --input '{"a":2,"b":3}'

扩展信息

实现类型动态库 (native-library)
目标平台Windows x64 / macOS arm64 / Linux x64 / Linux arm64
所需权限native.call

版本记录

指定版本安装：foundry install native-math --version 0.1.0 --grant native.call。
