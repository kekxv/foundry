OFFICIAL EXTENSION / JavaScript

serial-port

模拟串口设备的 UTF-8 请求响应，演示硬件通信的统一接口。

v0.1.0 · 已签名发布
ON THIS PAGE安装与调用扩展信息版本记录能力接口

串口 · 模拟插件
此版本使用模拟设备和固定数据，不会读取真实身份证、打开摄像头或执行真实 OCR。

安装与调用

先配置可信索引与公钥根，再使用以下命令。首次发布前可参考开发文档在本地构建体验。

foundry install serial-port
foundry run serial-port exchange --input '{"message":"PING"}'

扩展信息

实现类型JavaScript (javascript)
目标平台全部受支持平台
所需权限无需额外权限

版本记录

指定版本安装：foundry install serial-port --version 0.1.0。
