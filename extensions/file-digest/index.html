OFFICIAL EXTENSION / 命令行

file-digest

通过独立命令行程序计算文件 SHA-256，让原生能力保持清晰的接口。

v0.1.0 · 已签名发布
ON THIS PAGE安装与调用扩展信息版本记录能力接口

安装与调用

先配置可信索引与公钥根，再使用以下命令。首次发布前可参考开发文档在本地构建体验。

foundry install file-digest --grant process.spawn
foundry run file-digest digest --input '{"path":"/absolute/path/to/file"}'
